# Segurança

Se encontrar uma vulnerabilidade, evite publicá-la em issues com detalhes exploráveis ou segredos. Utilize os mecanismos de **Security Advisories / reporte privado** do GitHub, se habilitados pelo mantenedor.

Não inclua nos relatos senhas, cookies, chaves da Ronizada Quest, dados de nascimento, fotos de usuários ou dumps do banco.

Leia [docs/SEGURANCA_PUBLICACAO.md](docs/SEGURANCA_PUBLICACAO.md) para precauções ao publicar/operar o projeto.
